# Psychology of Learning — Quiz

Practice quiz for the NPTEL *Psychology of Learning* weekly assignments (weeks 0–12, 130 questions).

- **Quiz**: tap a week tab (or All) to jump straight in — each tab keeps its own progress; build a custom multi-week Mix in Settings, shuffle questions and/or options, live correct/wrong counter, explanation on wrong answers, auto-advance on correct answers, retry mistakes.
- **Study**: every question week-wise with the correct answer and explanation, searchable.

Static site — no build step needed to serve. Questions live in `data/weekNN.json`; run `python3 build.py` to regenerate `questions.js` after editing them.
